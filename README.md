# 🪔 Diwali Customer Analytics | Python, Pandas & Seaborn

## 📌 Project Overview

How can retailers understand customer purchasing behaviour and improve their festive-season sales strategy?

This project analyses **11,239 Diwali sales transactions** using Python, Pandas, and data visualization techniques to identify customer segments, high-performing regions, popular product categories, and occupational groups contributing to festive-season revenue.

The goal is to transform raw sales data into actionable business insights that can support customer targeting, regional marketing, and inventory planning.

## 🎯 Business Objectives

- Analyse customer purchasing behaviour across gender and age groups.
- Identify states contributing the most to total sales.
- Determine which product categories generate the highest revenue.
- Explore the relationship between customer occupations and spending.
- Visualize sales patterns to communicate findings clearly.
- Translate analytical results into practical business recommendations.

## 📊 Key Business Findings

### 1. Gender Analysis

Women account for approximately **70% of total sales** in the analysed dataset.

**Business implication:** Retailers could investigate women's purchasing preferences and tailor festive campaigns, product recommendations, and customer engagement strategies accordingly.

### 2. Age Group Analysis

Customers aged **26–35 represent approximately 40%** of the reported sales measure.

**Business implication:** This age group may be a priority segment for targeted offers, personalized promotions, and festive product bundles.

### 3. State-Wise Analysis

Uttar Pradesh, Maharashtra, Karnataka, and Delhi together contribute approximately **55% of reported revenue**.

**Business implication:** Retailers could prioritize regional campaign planning and inventory allocation in these markets while monitoring demand in other states.

### 4. Product Category Analysis

Food contributes approximately **32% of reported sales**, followed by Clothing and Electronics.

**Business implication:** Retailers can use category-level demand analysis to inform stock planning, product promotions, and festive bundles.

### 5. Occupation Analysis

Customers working in IT, Healthcare, and Aviation contribute approximately **38% of total spending**.

**Business implication:** These occupational segments could be explored for targeted campaigns, subject to validation against customer counts, average order values, and profitability.

*Note: Percentages and rankings should be interpreted according to the measure used in the notebook, such as total sales amount or transaction count.*

## 💡 Business Recommendations

Based on the analysis, retailers could:

- Develop targeted festive campaigns for high-contributing customer segments.
- Use state-level sales patterns to guide regional marketing investments.
- Plan inventory around leading product categories.
- Compare customer segments by revenue, order frequency, and average order value.
- Track campaign performance using conversion rates, revenue, and profit margins.
- Validate whether high sales contributions also translate into higher profitability.

## 🚀 How to Run the Project

### Option 1: Google Colab

1. Open the Jupyter Notebook in this repository.
2. Download the notebook or open it in Google Colab.
3. Upload the CSV dataset if required.
4. Update the dataset path in the notebook.
5. Run the cells sequentially to reproduce the analysis.

### Option 2: Run Locally

Clone the repository:

```bash
git clone https://github.com/Kamal-Damani/Diwali_Customer_Analytics_Python.git
```

Navigate to the project directory:

```bash
cd Diwali_Customer_Analytics_Python
```

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open `Diwali_Sales_analysis_Pandas.ipynb` and execute the cells.
